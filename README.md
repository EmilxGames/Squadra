# Squadra

Web app (PWA) per misurare l'assetto ruote col telefono: campanatura, convergenza, linea e angolo di spinta, più calcolatore per il metodo del filo.

Apri il sito pubblicato con GitHub Pages in Safari su iPhone, tocca Condividi → Aggiungi alla schermata Home. Aggiungi `?demo` all'indirizzo per vedere valori di esempio.
